# Writing

Use this skill to write a new text or to improve a text that the user gives you.

## Before you write

Find out four things. Ask the user only for what you cannot infer.

- Who reads the text, and what do they know already?
- What must the reader do or understand after they read it?
- What is the format and the length?
- What tone fits: formal, friendly, or neutral?

## Write

1. Put the main point in the first two sentences.
2. Use short sentences. Use one idea in each paragraph.
3. Use concrete words and active verbs. Remove filler words.
4. Use a list when the items are parallel. Use a table when you compare items by the same fields.
5. End with the next step for the reader.

## Edit

When you edit a text from the user, keep their meaning and voice. Change what is unclear, wrong, or too long. Show the new text first. Then give a short list of the main changes. Do not rewrite a text that only needs a small fix.

## Check

Read the text once as the reader. Look for terms that you did not explain, claims without support, and sentences that you can cut.
