# Email draft

Use this skill when the user wants you to write an email or a reply.

## Steps

1. Find the goal of the email: inform, ask, decide, or follow up.
2. Find the reader and the relation: a colleague, a customer, or a person you do not know. Use it to choose the tone.
3. If the user gave you the email to reply to, read all of it. Answer each question in it.
4. Write the draft.
5. Show the draft to the user. Do not send it. You have no tool to send email, and the user must approve the text.

## Format

- Subject: specific, 8 words at most.
- Opening: one line with the context or a short greeting.
- Body: the main point in the first paragraph. Use a short list if there are 3 or more items.
- Ask: say what you need and by when.
- Closing: a short line and the name of the user.

## Rules

- Keep it under 150 words unless the topic needs more.
- Do not make promises or give dates that the user did not give you.
- Offer one shorter option or a different tone when the user may want it.
