# HTML page

Use this skill when the user wants a quick web page: a landing page draft, a mockup of a
screen, a clickable prototype, a one-page report, or a small tool.

## Steps

1. Agree on the purpose, the audience, the content, and the style (for example "plain and
   formal" or "bold and playful"). Ask for a brand color and a logo when they matter.
2. Write the content first: the headings, the text, and the calls to action.
3. Build one `index.html` file with the CSS in a `<style>` block and any script in a
   `<script>` block. Use no build step. Load no outside script unless the user agrees.
4. Use a clear layout: a max width for text, a type scale with three or four sizes, a spacing
   scale, and one accent color. Use semantic tags (`header`, `main`, `section`, `nav`,
   `footer`).
5. Make it responsive: check a phone width of about 390 pixels and a desktop width.
6. Make it accessible: real text (not text in images), `alt` text, labels on inputs, enough
   contrast, and a visible focus state.
7. Save the file in the work folder. If you have a browser tool, open the page and take a
   screenshot to check it.

## Rules

- Use real content from the user. Mark placeholder text clearly.
- Do not copy the design, the logo, or the text of another site.
- Keep the file small enough to send. Use system fonts unless the user wants a web font.
