# Decision memo

Use this skill when the user must choose between options and wants a short document that
helps them or their team decide.

## Steps

1. Write the decision as one question, for example "Which CRM do we use from July?". Agree
   on it with the user.
2. Find the criteria that matter: cost, time, risk, quality, effort to change later, and the
   needs of the people affected. Ask the user to rank the top three.
3. List two to four real options. Include "do nothing" or "wait" when it is a real option.
4. For each option, give the facts against each criterion. Mark each fact as known,
   estimated, or assumed.
5. Give a recommendation and the main reason for it. State what would change the
   recommendation.
6. List the risks of the recommended option and how to reduce each one.

## Rules

- Keep facts and opinions separate.
- Do not hide the weak points of the recommended option.
- When the decision can be undone easily, say so. It changes how much analysis is useful.
- Keep the memo to one page when you can.

## Output

1. Decision (one sentence) and recommendation (one sentence).
2. A table: options in rows, criteria in columns.
3. Reasons, risks, and open questions.
4. The next step and its owner.
