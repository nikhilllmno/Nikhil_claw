# Content calendar

Use this skill when the user wants a plan of posts for one or more weeks: for a launch, an
event, a brand account, or a personal profile.

## Steps

1. Get the goal, the audience, the networks, the number of posts each week, the period, and
   the fixed dates (launches, events, holidays).
2. Choose three to five themes (content pillars) that fit the goal, for example "how-to",
   "customer results", "behind the scenes", and "news".
3. Mix the formats that each network supports: text, image, short video, poll, and thread.
4. Put the fixed dates in the calendar first. Then spread the themes so that no theme repeats
   on two days in a row.
5. For each post, write: the date, the network, the theme, the format, the first line, the
   main point, and the call to action.
6. Mark the posts that need an asset (an image, a video, or a quote from a person) and who
   must make it.

## Rules

- Do not invent customer stories, numbers, or quotes. Mark the places where the user must
  give real material.
- Check that the plan fits the time and the people of the user.
- Draft the full text of a post only when the user asks. Load the skill `social-post` for
  that if you have it.

## Output

A table with the columns: date, network, theme, format, first line, call to action, asset.
