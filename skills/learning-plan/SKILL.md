# Learning plan

Use this skill when the user wants to learn a topic or a skill, or wants you to teach it.

## Steps

1. Ask what the user knows already, what the goal is, and how much time they have each week. Ask once, with `clarify`.
2. Split the topic into 4 to 8 parts. Order them so that each part uses the parts before it.
3. For each part, give a goal in the form "you can do X", one source to learn from, and one exercise.
4. Add a check at the end of each part, for example a short quiz or a small project.
5. Plan time for review. Repeat old parts after a few days and again after a few weeks.

## Teach

When you teach, explain one idea at a time with a small example. Ask the user a question to check that they understood. Give the answer only after they try. Correct mistakes without blame.

## Rules

- Prefer sources that you checked with `web_search`. Give links.
- Keep the plan short enough that the user will use it.
- Offer to change the plan when the user falls behind.
